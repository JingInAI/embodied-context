# v1-1：从迭代经验到通用组件

基线：`v1` 的 `289a721`。本次在 `v1-1` 工作，保持十个组件和
`context.v1` / payload 1。设计依据是相邻 `../docs/` 的 decisions、spec、
component-contracts、activation-contract；这些冻结文档不在本次修改范围内。

## 经验及所有权

一次任务中出现过：名义输入与实际响应不一致；样本不足以支撑联合拟合；
已有局部进展被下一步撤销；示例对起始条件敏感；中断和基础设施错误被表面
分数掩盖；解释文字挤占有效历史。成功案例只证明该配置下的一次结果，不能
证明通用成功率提升，也不能把其中的坐标、阈值、动作、模型或任务名内置。

| 信息问题 | 所有者 | 可选扩展 |
| --- | --- | --- |
| 外部建议/示例的前提是否被当前证据支持 | task_context | decision_rules → decision_support；三值条件、来源、时效和配置匹配；只呈现已提供的建议，不生成动作 |
| 少量实际样本到底说明了什么 | response_evidence | query.kind=describe；按变量描述统计和显式请求的逐记录比值；不放松估计器支持条件 |
| 是否真的完成任务评估，故障发生在哪一层 | execution_feedback | 每段可选 outcome → outcomes；已报告评估与执行数量分别保留，不推断得分或失败原因 |
| 如何减少重复教学文字而保留决策数据 | renderer | explanation_detail=concise；全量 JSON/文字数据、引用、状态和限制原样保留，预算不足仍明确失败 |

不新增组件：上述信息已有唯一所有者。空间估计仍由 spatial_context 在显式
标定与几何假设下计算；观测不确定性仍归 observation_context；资源余额和
输出约束仍归各自组件。没有“机器人抓取流程”或“必须保住某状态”的内置策略。

## 兼容与验证

全部新领域字段可选；旧输入不会增加新输出字段。默认 explanation_detail=full，
旧渲染行为保留。使用新字段的严格旧消费方需要升级对应可选 schema；这是
前向兼容限制，不声称旧版本能接受新字段。新规则每次由宿主显式提供，不隐式
写入旧任务状态；示例通过已授权 reference 提供，不跨 run 自动学习。

测试覆盖纯推理、数据处理、外部操作等合成场景；验证旧套件、单样本与缺失、
过期/撤销/冲突证据、配置不匹配、未完成评估、状态恢复、三种显示格式、DAG、
增量重建和字节预算。禁止新依赖、backend、模型调用或基准执行。

## 从具体迭代到通用约束

| 迭代观察 | 可迁移经验 | 本次落实方式 |
| --- | --- | --- |
| 名义输入与实际效果不同 | 对比请求、执行与观测，不能把输入当成结果 | 保留执行前缀；对明确执行的输入/响应记录作描述 |
| 少量记录无法支撑多维局部模型 | 缺少预测支持不等于没有回顾性信息 | 新增 describe，不放松原估计器条件 |
| 后续操作可能破坏已有进展 | 已有证据应进入下一次决策，验证要求应显式化 | 宿主可提供条件建议；库不默认规定保留/撤销策略 |
| 示例依赖起始条件 | 成功案例必须说明适用前提，不能机械复制 | 谓词、时效、配置、来源和示例引用分别保留 |
| 一部分运行未完成评估 | 基础设施故障、中断和任务失败不可混算 | outcome 独立于执行 status 与数量，不补造 task_success |
| 重复解释占用上下文 | 优先保留事实和限制，说明长度可显式选择 | full/concise 两档，数据和引用不截断 |

本地动机证据：任务报告
`tasks-libero/libero-object-01/.agenttest/reports/libero-object-01_20261106_083558_566876.json`
（相对宿主 AgentTest-An 根目录）记录 `score=1.0/status=passed/error=null`。
该结果属于先前单次任务迭代，不属于本分支实验，也不构成跨任务的统计证据。
报告未复制进组件运行包；本分支不改任务文件、不安装到任务环境、不重新运行模型。
通用示例的事实、策略和阈值均由示例调用方显式提供，不是组件默认知识。

本次输出还显式携带规则 max_age_turns/required_bindings，避免只在隐藏请求中
保留适用条件。回归测试发现极大有限样本的均值中间值可能溢出，采用归一化求和
修复；这只是数值稳健性，不提升样本代表性或数值精度承诺。
